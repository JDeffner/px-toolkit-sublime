LSP-px — CK3 modding for Sublime Text

Install the separate LSP package with Package Control, then restart Sublime.
Run Paradox: Setup, configure CK3, and open a mod folder with descriptor.mod.
The latest stable language server downloads on first use and updates on restart.
Set px.auto_update_server to false to keep the cached version. Node 18+ is required on
Linux/macOS; Windows x64 can use the bundled runtime if Node is absent.
Run Paradox: Choose LSP Version to pin an earlier server or return to automatic updates.

See Preferences > Package Settings > LSP-px > Setup for the complete guide.
