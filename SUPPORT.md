# Support and maintenance

Start with the [wiki](https://github.com/JDeffner/px-toolkit-sublime/wiki), especially [installation](https://github.com/JDeffner/px-toolkit-sublime/wiki/Installation), [settings](https://github.com/JDeffner/px-toolkit-sublime/wiki/Settings), and [troubleshooting](https://github.com/JDeffner/px-toolkit-sublime/wiki/Troubleshooting).

## Where to ask

| Need | Route |
| --- | --- |
| Package bug or feature request | [Issue forms](https://github.com/JDeffner/px-toolkit-sublime/issues/new/choose) |
| Setup or usage question | Search existing issues, then open a question with your setup and what you tried |
| Security vulnerability | [Private reporting instructions](SECURITY.md) |
| Contribution or testing | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Take over maintenance | Open an issue describing your interest so a handover can be arranged |
| Language-server behavior across clients | [Main toolkit](https://github.com/JDeffner/paradox-modding-toolkit) |

For bugs, include the package revision, OS, Sublime build, LSP/server versions, relevant settings, and a minimal example. State whether the problem appears in a package command, LSP diagnostics, or Tiger output. Logs from Paradox Index Health and LSP Troubleshoot Server can help. Remove sensitive paths and data; do not upload complete games, private mods, or saves.

## Availability

I do not plan much further development of this Sublime Text package. My focus is the [main Paradox Modding Toolkit](https://github.com/JDeffner/paradox-modding-toolkit). I may fix bugs when time allows, but there is no planned feature or release schedule. Contributions are welcome. If you want to maintain this package, please [open an issue](https://github.com/JDeffner/px-toolkit-sublime/issues) to arrange a handover.

The package remains a release candidate until its acceptance checks are complete. Tests and static reports do not guarantee in-game behavior. See the [validation record](docs/VALIDATION.md) for performed checks and limitations.
